# Export format strategy

Export only the targets your project needs. This project offers two different paths; UI support and script support must not be confused.

| Format / output | Native preset workflow | Full batch script |
| --- | --- | --- |
| PNG | Web 1x/2x; iOS 1x/2x/3x; Android scale variants | Included, with platform folders and Android name normalization |
| SVG | Included in Web Essentials, Web Compatible and SVG Only | Included; inspect clipping, text and raster images |
| WebP | **Directly in Illustrator**, where the installed dialog supports WebP | Optional `cwebp` conversion tool, not a built-in JSX output |
| JPEG | Available manually in Illustrator; not included in the focused native presets | Optional 1x/2x, quality 85 |
| One combined PDF | Select marked artboards + PDF Only + Single File, or use the native helper | Automatic `_` / literal `*` routing |
| Xcode `.imageset` | Not generated by a format preset | Optional Python helper from the script's iOS PNG outputs |
| AVIF | No preset supplied | Not implemented |
| Android Vector Drawable XML | Not a direct preset export | Not implemented |
| App icons / store screenshots | Separate size/content workflow | Not implemented |
| Print-certified PDF/X | Requires a dedicated prepress workflow | Not implemented |

## Scale and naming assumptions

Design at the intended 1x logical size. iOS PNG profiles include 1x for compatibility plus 2x/3x. Android raster factors are 1x, 1.5x, 2x, 3x and 4x. Native scale presets do not normalize Android names or create the script's drawable resource tree. Do not automatically treat a large screenshot as a 1x asset.

Keep native Prefix empty. File bases should follow artboard names, with scale suffixes where needed. Use unique valid names; the native presets do not provide the full script's collision checks. A leading `_` or literal `*` is a project convention enforced by scripts, not by the native preset file. Never include marked pages in the native asset range when they are intended only for PDF.

## Color, background and quality

Prepare and inspect an RGB/sRGB screen workflow. The presets do not embed a color-conversion policy, transparency choice, artboard-background setting or WebP quality/lossless setting. Configure these in Illustrator. Higher scale cannot recover detail from a low-resolution placed image. Inspect fonts, raster effects, clipping, linked images and PDF order.

For crisp web logos and UI, SVG or lossless bitmap formats are useful starting points. Photos may benefit from JPEG or lossy WebP. Avoid exporting every available format and oversized scale without a target requirement.

## Validation status

Native preset structures and mocked script behavior are tested. Actual preset import and Illustrator rendering remain unverified. The supplied presets reuse observed format IDs from the maintainer's own exported file; no claim is made that this undocumented layout is identical in all Illustrator versions. Use Web Compatible when WebP is unavailable and report your exact tested versions.

See [native workflow](NATIVE_WORKFLOW.md) and [full-script testing](TESTING.md).
